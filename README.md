# Agent Board 📋
**نظام تنسيق وإدارة وكلاء الذكاء الاصطناعي (AI Agent Orchestration System)**

Agent Board هو نظام إدارة متكامل يجمع بين لوحة Kanban مرئية ومحرك تنسيق (Orchestrator) يعمل في الخلفية، مما يتيح لك إدارة مجموعة من وكلاء الذكاء الاصطناعي، تتبع مهامهم في الوقت الفعلي، وضمان استمرارية العمل من خلال نظام مراقبة ذكي.

---

## 🌟 المميزات الرئيسية

- **لوحة Kanban تفاعلية:** رؤية شاملة للمهام (Todo, In Progress, Blocked, Done) مع تحديثات فورية عبر WebSockets.
- **تنسيق تلقائي للمهام (Auto-Queue):** بمجرد انتهاء الوكيل من مهمة، يتم تعيين المهمة التالية الأعلى أولوية له تلقائياً.
- **مراقبة النبضات (Heartbeat Monitoring):** اكتشاف الوكلاء المتوقفين عن العمل (Stuck) وإعادة تشغيلهم تلقائياً.
- **تتبع التقدم:** شريط تقدم مباشر (0-100%) لكل مهمة يتم تحديثه بواسطة الوكلاء.
- **إدارة مركزية للوكلاء:** تسجيل وإدارة الوكلاء المحليين أو البعيدين مع تحديد منافذ الاتصال (Ports).

---

## 🏗️ بنية النظام

يعمل النظام وفق الهيكلية التالية:
- **واجهة المستخدم (Frontend):** تعمل على المنفذ `5173` (React/Vite).
- **الخادم الخلفي (Backend):** يعمل على المنفذ `3001` (Node.js/Express).
- **قاعدة البيانات:** SQLite محلية تُخزن في `~/.orchestrator/db.sqlite`.
- **الوكلاء (Agents):** خدمات مستقلة تتواصل مع الخادم عبر API لإرسال تحديثات الحالة.

## 🚀 التشغيل والتثبيت

### متطلبات التشغيل
- Node.js (v18 أو أحدث)
- npm

### التثبيت
قم بتنفيذ الأمر التالي لإعداد المشروع بالكامل (تثبيت المكتبات وإنشاء مجلد البيانات):
```bash
npm run setup
```

### التشغيل
لتشغيل الواجهة والخادم الخلفي معاً في وضع التطوير:
```bash
npm run dev
```
بعد التشغيل، يمكنك الوصول إلى اللوحة عبر: `http://localhost:5173`

### التشغيل التلقائي (macOS)
لجعل النظام يعمل كخدمة في الخلفية عند بدء التشغيل:
```bash
cp launchd/com.agentboard.orchestrator.plist ~/Library/LaunchAgents/
launchctl load ~/Library/LaunchAgents/com.agentboard.orchestrator.plist
```

## 🛠️ دليل الاستخدام السريع

### 1. إضافة وكيل (Agent)
من واجهة المستخدم، انقر على **(+)** في قائمة الوكلاء، وأدخل اسم الوكيل والمنفذ (Port) الذي يعمل عليه.

### 2. إنشاء مهمة (Task)
استخدم زر **New Task** لإضافة مهمة جديدة وتحديد أولويتها (`low`, `medium`, `high`, `urgent`).

### 3. تعيين المهمة
قم بتعيين المهمة لوكيل معين من خلال بطاقة المهمة في لوحة Kanban. ستنتقل المهمة تلقائياً إلى عمود **In Progress**.

### 4. تحديث التقدم (للمطورين)
يجب على الوكيل إرسال تحديثات دورية عبر endpoint النبضات:
```bash
curl -X POST http://localhost:3001/api/heartbeat \
  -H 'Content-Type: application/json' \
  -d '{"agentId": "ID", "taskId": "ID", "progress": 50, "status": "running", "message": "جارٍ العمل..."}'
```

## 🔌 واجهة برمجة التطبيقات (API Endpoints)

### المهام (Tasks)
- `GET /api/tasks` : جلب جميع المهام.
- `POST /api/tasks` : إنشاء مهمة جديدة.
- `POST /api/tasks/:id/assign` : تعيين مهمة لوكيل محدد.
- `DELETE /api/tasks/:id` : حذف مهمة.

### الوكلاء (Agents)
- `GET /api/agents` : جلب قائمة الوكلاء وحالاتهم.
- `POST /api/agents/register` : تسجيل وكيل جديد في النظام.
- `PATCH /api/agents/:id` : تحديث بيانات وكيل.

### التنسيق والمراقبة
- `POST /api/heartbeat` : استقبال نبضات الحياة وتحديثات التقدم من الوكلاء.
- `GET /api/events` : جلب سجل الأحداث الأخير في النظام.
